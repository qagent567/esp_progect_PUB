# Возможности и подтверждённые результаты

[Каталог возможностей](features.md) · [Текущая готовность](project-status.md)

Практическая основа AgriSwarm — локальная автоматика на ESP32, настройка оборудования и правил, обмен между узлами и диагностика. Это позволяет начать с одной платы и постепенно проверить распределённый сценарий.

Описание функции, успешная сборка и испытание на оборудовании — разные уровни подтверждения. В этой редакции отмечены реализованные возможности и успешные сборки; проверка новых исправлений на физических ESP32 ещё предстоит.

Дальность, масштаб сети, экономия ресурсов и длительная надёжность будут описаны числами только после измерений. [Методика](../AUDIT_AND_TESTING.md).

Для знакомства: [обзор проекта](project-overview.md). Для выбора оборудования: [поддерживаемые типы](../03_Hardware_Interaction_and_Node_Lifecycle.md).
