# Справочные параметры

[Готовность](project-status.md) · [Команды](../06_CLI_Reference.md)

| Параметр | Значение или граница |
|---|---|
| Профиль проверенной сборки | ESP32 `wemos_d1_mini32` |
| Скорость консоли | 115200 бод |
| Отображаемая версия разработки | v4.0.4; сверяйте также дату комплекта |
| Веб-сервер | Локальный HTTP, порт 80 |
| Штатный адрес точки доступа | 192.168.4.1; фактический адрес уточняйте на устройстве |
| Типы входов | Цифровой, аналоговый, режимы DHT11/DHT22 |
| Типы выходов | Цифровой, реле, сервопривод |
| Хранение конфигурации | Встроенная файловая память LittleFS |
| Максимальное число узлов и дальность | Подтверждённые значения не опубликованы |
| Длительная автономная работа от батареи | Измерения не опубликованы |

Логический угол сервопривода ограничен возможностями настройки и механики. Наличие диапазона 0–180 в интерфейсе не даёт разрешения двигать любой механизм до крайних положений.

Значения времени в командах часто задаются в миллисекундах: 1000 мс = 1 с, 30000 мс = 30 с. Уточняйте единицы в подсказке конкретной команды.
