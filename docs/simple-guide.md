# AgriSwarm простыми словами

Плата получает показание, правило выбирает действие, подключённое устройство его выполняет. Несколько таких плат могут обмениваться данными. Пользователь задаёт настройки через консоль или подходящий интерфейс, без написания прошивки.

Начните с [обзора проекта](project-overview.md), посмотрите [сценарии](use-cases.md) и [возможности](features.md). Если плата уже у вас, переходите к [первому запуску](getting-started.md).
