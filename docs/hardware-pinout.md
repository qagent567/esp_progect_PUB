# Выбор GPIO

[Подключение](hardware-wiring.md) · [Безопасность](hardware-safety.md)

GPIO — номер сигнального контакта микроконтроллера. Он не всегда совпадает с номером ножки разъёма или обозначением D на плате. Приведённые ограничения относятся к классическому ESP32; для S2, S3 и C3 нужна отдельная схема.

| Контакты | Что учитывать |
|---|---|
| GPIO1 и GPIO3 | Обычно используются для последовательной консоли. |
| GPIO6–11 | Обычно связаны с памятью модуля; не используйте их в пользовательской схеме. |
| GPIO16–17 | Могут быть заняты памятью в зависимости от модуля. |
| GPIO34–39 | Только вход; встроенной подтяжки нет. |
| GPIO0, 2, 5, 12, 15 | Влияют на режим загрузки; внешняя схема не должна нарушать запуск. |
| GPIO32–39 | Область ADC1; не все контакты выведены на каждой плате. |

Ограничения контактов сверены с [руководством Espressif по GPIO](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/api-reference/peripherals/gpio.html). При включённом Wi-Fi для аналоговых измерений используют подходящие входы ADC1, учитывая ограничения ADC2.

В примерах стенда используются GPIO26 для кнопки, GPIO27 для светодиода и GPIO34 для аналогового датчика. Это примеры назначений: до подключения проверьте наличие и свободность контактов на своей плате, включая использование SD-картой и другими модулями.

Не назначайте один GPIO двум устройствам. Выбор контакта в интерфейсе не заменяет проверки электрической схемы.
