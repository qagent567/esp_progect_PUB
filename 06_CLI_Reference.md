# Консоль: справочник основных команд

[Главная](README.md) · [Готовые примеры](docs/command-examples.md) · [Группы команд](docs/cli-dictionary.md)

Консоль — текстовое управление AgriSwarm через USB. Скорость последовательного порта: **115200 бод**. Вводите команды по одной и дожидайтесь ответа. Обозначения в угловых скобках нужно заменить своими значениями; квадратные скобки обозначают необязательные параметры.

Справочник сверён с текущей разработкой 19 сентября 2026 года. Список доступных команд установленной прошивки показывает `help`.

## Начальная диагностика

| Команда | Что показывает |
|---|---|
| `help` | Справку по командам. |
| `status` | Основное состояние узла. |
| `sysinfo` | Сведения об устройстве. |
| `memory` | Состояние памяти. |
| `uptime` | Время с момента запуска. |
| `fs_info` | Состояние файлового хранилища. |
| `system_diag` | Сводную диагностику. |
| `license` | Лицензионную информацию. |

## Оборудование

| Команда | Назначение |
|---|---|
| `pin_wizard` | Интерактивно добавить устройство. |
| `pin_list` | Посмотреть настроенные устройства. |
| `pin_info <имя>` | Узнать параметры и последнее показание. |
| `pin_config <имя>` | Открыть мастер изменения настройки. |
| `pin_state <имя> <0 или 1>` | Задать состояние цифрового выхода. |
| `pin_save <имя>` | Сохранить настройку устройства. |
| `pin_save_all` | Сохранить настройки всех пинов. |
| `pin_revert <имя>` | Восстановить сохранённую настройку. |
| `servo_set <имя> <угол>` | Задать угол локального сервопривода. |
| `servo_info <имя>` | Посмотреть состояние сервопривода. |
| `sensor_status` | Посмотреть состояние датчиков. |

`pin_delete <имя>` удаляет настройку и связанные правила. Перед удалением переведите физическую нагрузку в безопасное состояние: удаление записи не является аппаратным выключателем.

### Явная настройка

```text
pin_setup <имя> <тип> <gpio> <тема> [параметры_типа]
```

| Тип | Параметры после номера GPIO |
|---|---|
| `RELAY`, `DIGITAL_OUT` | `<тема> [начальное_состояние]` |
| `DIGITAL_IN` | `<тема> <интервал_мс> [режим] [дребезг_мс] [удержание_мс]` |
| `ANALOG_IN` | `<тема> <нижний_порог> <верхний_порог> [интервал_мс]` |
| `DHT11`, `DHT22`, `DHT11_HUM`, `DHT22_HUM` | `<тема> <нижний_порог> <верхний_порог> [интервал_мс]` |
| `SERVO` | `<тема> [начальный_угол] [мин_угол] [макс_угол] [скорость] [плавность] [отключение_сигнала] [задержка_мс]` |

Для цифрового входа задавайте интервал явно, от 50 мс; в таблице он намеренно указан обязательным. Режимы кнопки: `0` — обычный уровень, `1` — переключение при нажатии, `2` — нажимная кнопка. Для сервопривода предпочтителен мастер: после настройки отдельно проверяйте фактический начальный угол и ограничения механизма.

| Команда | Назначение |

## Сеть и браузер

| Команда | Назначение |
|---|---|
| `node_list` / `node_info <id>` | Видимые узлы и подробности. |
| `topics_tree` | Дерево объявленных ресурсов. |
| `topics_subscriptions` | Текущие подписки. |
| `topics_manage subscribe <nodeId> <deviceId> sensor` | Подписка на конкретный удалённый датчик. |
| `topics_manage unsubscribe <nodeId> <deviceId> sensor` | Отмена такой подписки. |
| `wifi_status` | Состояние Wi-Fi. |
| `host_status` | Состояние точки доступа. |
| `host_start` | Запуск точки доступа. |
| `webserver start` / `webserver status` | Запуск веб-сервера и его состояние. |
| `webserver stop` | Остановка веб-сервера. |

`mesh_send` передаёт сообщение: ответ об отправке не равен подтверждению исполнения произвольной удалённой команды. Для управляющих сценариев используйте согласованный путь настройки устройств и проверяйте фактический результат.

## Сохранение и обслуживание

`config_backup` и `config_restore` работают с основными настройками и сохранёнными файлами пинов, правил и задач. Копии остаются на плате; это не полный переносимый образ всей установки. [Состав и особенности восстановления](docs/littlefs-structure.md).

Команды `factory_reset`, `config_reset`, `pin_reset_all`, `sd_format` и очистки журналов могут удалить данные. Они не входят в обычную последовательность первого запуска. Перед их применением изучите подсказку и последствия для своего комплекта.
