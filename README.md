# AgriSwarm

**Система, в которой датчики и устройства работают вместе — даже без интернета.**

AgriSwarm помогает организовать автоматику теплицы, небольшого участка или учебного стенда. Плата ESP32 получает показания датчиков, проверяет заданные пользователем условия и управляет подключённым оборудованием. Несколько плат могут обмениваться данными и командами по радиосвязи.

Например: датчик замечает повышение температуры, а настроенное правило подаёт команду приводу форточки. Решение принимается на устройстве; для локального сценария постоянно включённый компьютер и облачный сервис не нужны.

[Обзор проекта](docs/project-overview.md) · [Возможности](docs/features.md) · [Первый запуск](docs/getting-started.md) · [Статус разработки](docs/project-status.md)

## Что даёт AgriSwarm

| Возможность | Практическая польза |
|---|---|
| **Работа на самой плате** | Локальные правила выполняются без подключения к интернету. |
| **Обмен между платами** | Датчик и управляемое устройство могут находиться на разных узлах. |
| **Настройка без написания прошивки** | Имена устройств, условия и действия задаются через интерфейсы настройки. |
| **Разные способы управления** | Есть консоль по USB и локальная веб-панель; приложения для ПК и телефона развиваются отдельно. |
| **Диагностика** | Можно посмотреть показания, состояние сети, правила и сообщения об ошибках. |
| **Сохранение настроек** | Конфигурация хранится на плате и загружается при следующем включении. |

## Как это устроено

![Схема: датчик передаёт показание плате; правило на плате выбирает действие; другая плата может участвовать через радиосвязь](assets/agriswarm-public-system.svg)

**Узел** — это одна ESP32 с подключёнными датчиками или исполнительными устройствами. **Правило** — условие вида «если температура выше порога, включить вентиляцию». Обмен между узлами расширяет такой сценарий на несколько точек участка.

## На каком этапе проект

AgriSwarm находится на стадии **инженерного прототипа**. В текущей разработке реализованы локальные датчики, управление выходами, правила, планирование, сетевой обмен и диагностика. Исправления прошивки прошли сборку; испытания обновлённой версии на физических платах ещё предстоят.

Эта редакция документации подготовлена **19 сентября 2026 года**. Дальность связи, допустимое число узлов и длительная надёжность будут указаны по результатам испытаний. Доступность функций в конкретном комплекте описана в [статусе проекта и сведениях о совместимости](docs/project-status.md).
