# Первый запуск

[Главная](../README.md) · [Оборудование](hardware-wiring.md) · [Если возникла проблема](troubleshooting.md)

Первый результат — плата отвечает на команды, показывает свой статус и сохраняет пробную настройку. Начните с одной ESP32.

## Что понадобится

- Совместимая плата ESP32. Проверенный профиль сборки — `wemos_d1_mini32`; совместимость других вариантов ESP32 уточняется отдельно.
- USB-кабель с передачей данных и компьютер с последовательным терминалом.
- Совместимый комплект готовой прошивки от автора.
- Для следующего шага — кнопка или светодиод с резистором.

SD-карта, внешние часы и вторая ESP32 для первого запуска не требуются.

## 1. Проверьте комплект

Откройте [инструкцию установки](firmware.md). Выпуск документации не означает наличие готовых файлов прошивки. Убедитесь, что указаны подходящая плата и порядок записи. Ознакомьтесь с [лицензией](../LICENSE).

## 2. Подключите плату

При первой загрузке оставьте плату без внешних механизмов. Установите комплект по инструкции автора. После записи закройте загрузчик, откройте последовательный терминал на **115200 бод** и выберите порт подключённой платы. Завершайте ввод команды переводом строки.

## 3. Проверьте ответ

Введите по одной команде:

```text
help
status
pin_list
node_list
```

Ожидается справка, состояние платы и списки устройств. Пустой список пинов на новой плате нормален; отсутствие соседей у единственного узла тоже нормально. Если нет ответа, проверьте USB-кабель, порт и скорость терминала.

## 4. Настройте первое устройство

Сначала сверяйте схему с [рекомендациями по подключению](hardware-wiring.md). Затем откройте мастер:

```text
pin_wizard
```

Укажите имя, тип, номер GPIO и тему данных. Для имён удобно использовать короткие латинские названия без пробелов: `button`, `lamp`. Тема — имя потока показаний или управления, например `demo/button`.

Мастер помогает заполнить параметры, но не проверяет физическое подключение. Для полностью заданного примера используйте [стенд «кнопка — светодиод»](command-examples.md).

## 5. Сохраните и проверьте

```text
pin_list
pin_save_all
```

После сообщения об успешном сохранении перезапустите плату при безопасном состоянии стенда. Повторите `pin_list` и убедитесь, что настройка сохранилась. Если нет — изучите сообщение об ошибке, прежде чем продолжать.
