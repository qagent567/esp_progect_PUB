# Если система работает не так, как ожидается

[Первый запуск](docs/getting-started.md) · [Поддержка](SUPPORT.md)

Сначала проверьте питание и связь с платой, затем локальное устройство, и только после него правило и сеть. Такой порядок помогает отделить неисправность подключения от ошибки настройки.

| Симптом | Что проверить |
|---|---|
| Нет вывода по USB | Кабель с передачей данных, правильный порт, скорость 115200; порт не занят другой программой. |
| Плата постоянно перезапускается | Питание без внешних нагрузок, журнал запуска, подключённые к загрузочным GPIO цепи. |
| Устройство не добавляется | Имя, тип, свободный GPIO и обязательная тема; полный ответ команды. |
| Кнопка не регистрируется | Явно заданный интервал от 50 мс, GPIO, соединение с GND, режим входа. |
| Аналоговое значение странное | Допустимое напряжение, ADC1, общий провод, показания до калибровки. |
| Выход не реагирует | Имя устройства, физическое питание модуля, ручной приоритет и защитное состояние. |
| Правило не срабатывает | Точное имя источника, включённость правила, условие, актуальность показания, конфликтующее правило. |
| Соседний узел не виден | Совместимость прошивок, настройки сети, питание второй платы; повторить опыт рядом. |
| Узел виден, показания не приходят | Ресурс объявлен и на него создана подписка с правильными ID. |
| Браузер не открывает панель | Сеть, фактический адрес, состояние `webserver` и страница ожидания. |
| После перезапуска нет настройки | Результат сохранения и состояние хранилища. |
| Приложение показывает неправдоподобные данные | Не включён ли демонстрационный режим. |

## Короткая диагностика

```text
status
memory
fs_info
pin_list
rule_list
node_list
```

Сохраните ответ и сообщения перед ошибкой. Для уточнения используйте `pin_info <имя>`, `rule_info <id>`, `rule_states` и `topics_subscriptions`.

## Чего не делать первым шагом

Не форматируйте память и не выполняйте общий сброс только потому, что интерфейс не открылся. Это может удалить настройки и затруднить поиск причины. Перед очисткой сохраните диагностические сведения и прочитайте [раздел хранения](docs/littlefs-structure.md).

## Как сообщить о проблеме

Укажите плату, версию и дату комплекта, схему, питание, точные шаги и полный ответ команды. Пароли и личные данные удалите. [Шаблон обращения](SUPPORT.md).
