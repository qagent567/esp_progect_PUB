# Памятка по загрузчику прошивки

[Установка прошивки](../docs/firmware.md) · [Первый запуск](../docs/getting-started.md)

В рабочем каталоге проекта может находиться старый графический загрузчик. Его наличие не означает, что рядом лежит полный совместимый комплект прошивки. Подготовленный пакет публикации документации содержит эту памятку, но не исполняемые файлы и бинарные образы.

Для классической ESP32 загрузчик ожидает файлы `bootloader.bin`, `partitions.bin` и `firmware.bin` одного комплекта. До запуска записи проверьте их назначение, модель платы и адреса по инструкции выпуска. Не используйте автоматический выбор адреса при неполном комплекте.

Готовые файлы и инструкцию ищите в [выпусках проекта](https://github.com/qagent567/esp_progect_PUB/releases). Если опубликована только документация, запросите совместимый комплект у автора через [поддержку](../SUPPORT.md).

Перед загрузкой отключите нагрузку и закройте программы, занимающие последовательный порт. После установки проверьте плату на 115200 бод по [первому запуску](../docs/getting-started.md).
