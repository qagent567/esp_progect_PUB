# Готовые примеры: от ручного управления к правилу

[Справочник команд](../06_CLI_Reference.md) · [Схема подключения](hardware-wiring.md)

Примеры сверены с текущими обработчиками команд; физический прогон новой редакции ещё предстоит. Используйте отдельный низковольтный стенд и свободные контакты. Команды вводятся в консоль AgriSwarm по одной строке.

## 1. Светодиод: ручное включение

Для классической ESP32 в этом примере используется GPIO27: GPIO → резистор → светодиод → GND. Убедитесь, что контакт выведен на вашей плате и не занят. Сопротивление выбирается по светодиоду и допустимому току.

```text
pin_setup lamp DIGITAL_OUT 27 demo/lamp 0
pin_state lamp 1
pin_state lamp 0
pin_save lamp
```

Ожидается: создаётся выход `lamp`, индикатор включается и выключается, настройка сохраняется. `demo/lamp` — обязательная тема; краткая запись без неё не создаёт выход.

## 2. Кнопка

Подключите кнопку между свободным GPIO26 и GND. Вход использует внутреннюю подтяжку. Явно зададим интервал 50 мс и режим обычного входа:

```text
pin_setup button DIGITAL_IN 26 demo/button 50 0 20 5000
pin_info button
pin_save button
```

Для такого подключения отпущенная кнопка даёт `1`, нажатая — `0`. В этой последовательности интервал указан явно, чтобы не полагаться на различия между значениями по умолчанию и проверкой настройки.

## 3. Правила «нажата — включить, отпущена — выключить»

В стенде используются только `button` и `lamp` из предыдущих шагов. Локальные правила здесь ссылаются на имя входа `button`.

```text
rule_add demo_on "Кнопка вкл" button == 0 set_pin lamp 1
rule_add demo_off "Кнопка выкл" button == 1 set_pin lamp 0
rule_list
rule_states
```

Названия «Кнопка вкл» и «Кнопка выкл» — произвольные подписи примера. Ожидаемая проверка: после окончания временного ручного приоритета нажатие включает индикатор, отпускание выключает. Посмотрите состояние правил и фактический индикатор: сообщение о принятии настройки не заменяет проверку выхода.

## 4. Проверка правила заданным значением

На стенде без опасных нагрузок можно отдельно передать значение в обработку правил:

```text
sim_sensor button 0
sim_sensor button 1
```

Это разовая имитация показания. Она может вызвать настоящее переключение `lamp`, не калибрует датчик и не доказывает работу физической кнопки. Следующее реальное показание может изменить результат.

## 5. Остановить опыт

```text
rule_enable demo_on off
rule_enable demo_off off
pin_state lamp 0
```

Для удаления только двух правил этого примера:

```text
rule_delete demo_on
rule_delete demo_off
```

## 6. Пример аналогового измерения

Если на свободный вход ADC1 GPIO34 подан допустимый сигнал совместимого датчика:

```text
pin_setup soil ANALOG_IN 34 demo/soil 0 4095 30000
pin_info soil
pin_save soil
```

Здесь интервал — 30000 мс, то есть 30 секунд. Значения `0` и `4095` задают диапазон настройки, а не преобразование в проценты. Сначала изучите показания конкретного датчика в сухой и влажной среде.

## 7. Проверка сети без управляющих команд

```text
node_list
topics_tree
topics_subscriptions
```

Эти команды показывают обнаруженные узлы, ресурсы и подписки. Следующий шаг — [настройка двух плат](../04_Mesh_Network_and_Data_Routing.md).
