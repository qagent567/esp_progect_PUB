# Обмен данными и внешние интерфейсы

[Сеть](../04_Mesh_Network_and_Data_Routing.md) · [Интеграции](../07_Gateway_Integration.md)

Раздел предназначен для опытного пользователя. Он описывает назначение обмена, без публикации внутренних реализаций прошивки. Полная стабильная спецификация для стороннего клиента пока не заявлена.

## Какие данные передаются

Узлы сообщают о себе и доступных ресурсах, передают показания подписанных датчиков, команды устройств и подтверждения обработки. Источник, адресат и конкретное устройство должны быть определены однозначно.

Сетевое сообщение, подтверждение его обработки и физическое действие — разные наблюдения. Устройство может принять команду, но физическую работу механизма можно подтвердить только наблюдением или обратной связью.

## Локальный HTTP-интерфейс

В текущей разработке доступны маршруты чтения `/api/status`, `/api/pins`, `/api/nodes` и `/api/rules`. Они зависят от состояния локального веб-сервера. Часть маршрутов в режиме ожидания возвращает `503`; сначала активируйте панель.

Интерфейсы изменения настроек и отправки команд нужно проверять по совместимому выпуску. Адрес HTTP-панели не является защищённым облачным API. Показания стороннего клиента сопоставляйте с фактическими данными платы.

## Совместимость

Повторы и подтверждения управляющих сообщений менялись при исправлениях прошивки. Для двух узлов предпочтителен один проверенный комплект. Одинаковая отображаемая строка версии без даты комплекта может быть недостаточна.

CRC проверяет целостность, а не права отправителя. [Ограничения защиты](../09_Security_and_Constraints.md).
