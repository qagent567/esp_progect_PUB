# Словарь простыми словами

[Главная](../README.md) · [Команды](../06_CLI_Reference.md)

| Термин | Значение |
|---|---|
| ESP32 | Микроконтроллер, на котором работает прошивка. В разговоре так часто называют всю плату. |
| Прошивка | Программа, записанная в память устройства. |
| Узел | Одна плата с её устройствами и настройками. |
| GPIO, пин | Сигнальный контакт микроконтроллера. |
| Датчик | Источник измерения: например, температуры. |
| Исполнительное устройство, актуатор | Устройство, выполняющее действие: например, привод. |
| Реле | Переключатель электрической цепи, управляемый отдельным сигналом. |
| Сервопривод | Привод, которому задаётся положение. |
| Тема, topic | Имя потока данных или управления. |
| Подписка | Настройка получения данных определённого удалённого устройства. |
| Правило | Условие и действие, которое с ним связано. |
| Гистерезис | Разница между порогами включения и выключения. |
| Консоль, CLI | Интерфейс, в котором команды вводятся текстом. |
| Serial | Последовательное соединение, используемое для консоли. |
| Mesh | Сетевая часть, связывающая узлы; её конкретные свойства зависят от реализации. |
| ACK | Ответ получателя о результате обработки сообщения. |
| CRC | Проверка целостности данных; не подтверждение полномочий отправителя. |
| Fail-safe | Переход к заранее выбранному безопасному состоянию при определённых условиях сбоя. |
| LittleFS | Файловое хранилище во встроенной памяти платы. |
| BlackBox | Средства сохранения диагностических сведений о работе и сбоях. |
| RTC-память | Область памяти ESP32, которая сохраняется при некоторых видах перезапуска. |
| API | Интерфейс обмена данными между программами. |
| Демо-режим | Имитация работы для знакомства с интерфейсом. |
