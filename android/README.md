# 📱 Мобильное PWA & Android-приложение AgriSwarm

Этот каталог содержит исходный код клиентского мобильного приложения для управления децентрализованной mesh-сетью **AgriSwarm** на базе микроконтроллеров ESP32.

Приложение разработано по концепции **Zero-Dependency** и **Offline-First**, что позволяет запускать его в полевых условиях без интернета при подключении к локальной Wi-Fi точке доступа ESP32.

---

## 🏗️ Архитектурные особенности
Приложение работает в связке с прошивкой версии **AgriSwarm-AppReady** (компилируется с отключенным флагом `#undef ENABLE_EMBEDDED_WEB_UI`). 

При такой схеме:
1. Файлы интерфейса хранятся **на самом смартфоне** пользователя, освобождая около **80 КБ Flash** и дефицитную оперативную память (RAM) на ESP32.
2. Приложение общается с платой по беспроводной сети через легкие REST-запросы (`/api/status`, `/api/pins/toggle`) и получает системные логи через SSE (Server-Sent Events) поток `/events`.
3. При невозможности связаться с платой, приложение автоматически активирует высокоточный **Demo Mode (Симулятор)** датчиков, правил и mesh-сети для демонстрации и отладки без физического оборудования.

## 🚀 Как запустить на ПК / Смартфоне

### Вариант 1. Запуск без установки (Режим разработчика)
Просто откройте файл `index.html` в любом современном браузере. Приложение по умолчанию запустится в Demo-режиме. Вы можете ввести IP-адрес вашей платы и нажать «Подключить» для перехода в живой режим.

### Вариант 2. Установка как PWA (Progressive Web App)
Для полноценной оффлайн работы рекомендуется запускать интерфейс через веб-сервер.
1. Запустите любой локальный HTTP-сервер в этой папке. Например:
   ```bash
   npx http-server ./
   ```
2. Откройте выданный адрес (например, `http://localhost:8080`) в браузере Google Chrome на вашем Android-устройстве.
3. В меню браузера выберите **«Добавить на главный экран»** (или «Установить приложение»).
4. На рабочем столе появится иконка AgriSwarm. Приложение будет открываться на весь экран без адресной строки и кэшироваться оффлайн через `sw.js`.

## 📦 Сборка нативного Android-приложения (`.apk`) через Capacitor

Вы можете упаковать эти файлы в нативный установочный файл `.apk` для Android с помощью платформы **Capacitor** от Ionic.

### Требования:
* Установленный [Node.js](https://nodejs.org/) (версии 16+)
* Установленная среда [Android Studio](https://developer.android.com/studio) и Android SDK

### Шаги сборки:

1. **Инициализация npm проекта в этой папке:**
   ```bash
   npm init -y
   ```

2. **Установка Capacitor CLI и Core:**
   ```bash
   npm install @capacitor/core @capacitor/cli
   ```

3. **Инициализация конфигурации приложения:**
   ```bash
   npx cap init AgriSwarm com.agriswarm.app --web-dir=.
   ```
   * *Примечание:* Укажите имя `AgriSwarm` и индентификатор пакета (например, `com.agriswarm.app`). Параметр `--web-dir=.` указывает, что наши HTML/CSS/JS файлы лежат прямо в корне папки `android`.

4. **Добавление платформы Android:**
   ```bash
   npm install @capacitor/android
   npx cap add android
   ```

5. **Синхронизация веб-ресурсов с Android-проектом:**
   ```bash
   npx cap sync
   ```

6. **Сборка APK в Android Studio:**
   Запустите Android Studio для сборки и подписи готового пакета:
   ```bash
   npx cap open android
   ```
   * В открывшемся окне Android Studio выберите: **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
   * Готовый файл `.apk` будет сохранен в папке `android/app/build/outputs/apk/debug/app-debug.apk`. Скопируйте его на телефон и установите!

## 🎨 Описание функционала UI
* **Дашборд:** Отображает температуру воздуха и влажность почвы на графиках, текущий заряд батареи и статус энергосбережения. Дает возможность вручную переключать реле (насос, вентиляция, свет).
* **Карта ESP32:** 2D-рисунок платы. Нажатие на контакт открывает панель настройки (назначить датчик или реле, задать интервалы опроса).
* **Swarm Mesh:** Динамическая схема соединений роя, показывающая топологию, RSSI сигнала и роли узлов (Gateway, Node).
* **Правила:** Простой визуальный конструктор для создания автоматизации (ЕСЛИ датчик ТО реле НА время).
* **Терминал:** Эмулятор консоли с поддержкой `help`, `status`, `node_list` и выгрузкой отчетов черного ящика (`blackbox rtc`).
