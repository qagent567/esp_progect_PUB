# Практические маршруты

[Главная](../README.md) · [Полная навигация](../00_Master_Index.md)

## Добавить датчик

Проверьте его тип и напряжение → выберите свободный контакт → запустите `pin_wizard` → посмотрите показание → сохраните настройку → проверьте после включения. [Оборудование](../03_Hardware_Interaction_and_Node_Lifecycle.md).

## Сделать реакцию на кнопку

Сначала проверьте светодиод вручную, затем кнопку, затем создайте два правила. [Полная последовательность](command-examples.md).

## Изменить порог

Посмотрите `rule_info <id>`, внесите изменение через поддерживаемый редактор или мастер, затем проверьте значение ниже и выше порога. Отдельно проверьте обратное переключение. [Правила](automation.md).

## Получать показания с другой платы

Проверьте обе платы локально → найдите узел и ресурс → создайте подписку → убедитесь в обновлении данных → подключите правило. [Настройка сети](../04_Mesh_Network_and_Data_Routing.md).

## Подготовить систему к выступлению

Подпишите элементы, проверьте питание, пройдите все шаги опыта и приготовьте ответы о текущей готовности. [План демонстрации](demonstration.md).

## Найти причину проблемы

Идите от питания к устройству, затем к правилу и сети. Сохраните сообщение об ошибке до сброса. [Диагностика](../08_Troubleshooting.md).
