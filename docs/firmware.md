# Получение и установка прошивки

[Первый запуск](getting-started.md) · [Статус выпуска](project-status.md) · [Лицензия](../LICENSE)

Прошивка AgriSwarm распространяется в готовом виде по условиям автора. Исходный код прошивки закрыт; для установки не нужно собирать проект самостоятельно.

## Где искать

Проверьте [выпуски публичного репозитория](https://github.com/qagent567/esp_progect_PUB/releases). Выпуски с документацией могут не содержать установочных файлов. Если совместимый комплект не опубликован, обратитесь к автору через [поддержку](../SUPPORT.md).

## Что должно быть указано в комплекте

| Данные | Зачем нужны |
|---|---|
| Модель платы | ESP32, ESP32-S3 и ESP32-C3 не взаимозаменяемы при выборе бинарного файла. |
| Номер и дата выпуска | Позволяют сопоставить прошивку и документацию. |
| Файлы и адреса записи | Определяют правильную установку на чистую плату. |
| Контрольные суммы, если опубликованы | Позволяют проверить, что файлы скачались без изменений. |
| Порядок обновления | Объясняет, сохраняются ли настройки и требуется ли их перенос. |

Имеющийся загрузчик для классической ESP32 рассчитан на раздельные `bootloader.bin`, `partitions.bin` и `firmware.bin`. Его типовые адреса — `0x1000`, `0x8000` и `0x10000` соответственно. Используйте их только для комплекта, который явно предусматривает такую схему. Объединённый образ может требовать другой адрес.

## Последовательность

1. Сохраните сведения о текущих настройках и безопасно отключите исполнительные устройства.
2. Подключите ESP32 через USB и выберите её порт.
3. Укажите файлы одного совместимого комплекта.
4. Выполните запись по инструкции выпуска и дождитесь результата.
5. Закройте загрузчик, откройте терминал на 115200 бод и проверьте `status`.
6. Проверьте список устройств и пробное действие до подключения рабочей нагрузки.

Не продолжайте установку старым загрузчиком, если у него отсутствуют ожидаемые файлы: он может выбрать другой адрес записи. Не смешивайте загрузчик, таблицу разделов и приложение из неизвестных комплектов.

## Обновление по сети

В веб-интерфейсе предусмотрен путь обновления, но его пригодность зависит от разметки памяти и конкретного комплекта. В текущем профиле нет подтверждённого пользовательского сценария сетевого обновления. Для первого запуска ориентируйтесь на USB.
