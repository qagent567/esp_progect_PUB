# Локальная веб-панель

[Первый запуск](docs/getting-started.md) · [Сеть](04_Mesh_Network_and_Data_Routing.md) · [Приложения](07_Gateway_Integration.md)

Панель открывается в браузере телефона или компьютера, который имеет сетевой доступ к ESP32. Для этого не нужен облачный аккаунт. Доступность страницы зависит от состояния Wi-Fi и запуска веб-сервера на плате.

## Подключение

Через консоль проверьте:

```text
wifi_status
host_status
webserver status
```

Если используется точка доступа платы, её можно запустить командой `host_start`; веб-сервер — командой `webserver start`. Подключитесь к сети, имя и параметры которой показывает настроенный узел. Не используйте пароль из случайной старой инструкции.

Откройте адрес платы по HTTP. Для штатной точки доступа предусмотрен адрес `http://192.168.4.1`; при работе через роутер адрес может отличаться. Фактический адрес уточняйте по состоянию устройства.

## Режим ожидания

Сервер запускается со страницей ожидания. На ней нужно активировать интерфейс. При отсутствии активности панель может снова перейти в ожидание. В этом режиме запросы к части API получают ответ о недоступности; это само по себе не означает сбой платы.

Закрытие браузера не отменяет уже сохранённые локальные правила. Наличие открытой вкладки также не подтверждает, что значения свежие: проверяйте обновление данных.

## Что можно посмотреть и настроить

| Раздел | Назначение |
|---|---|
| Состояние | Время работы, память, сведения об узле. |
| Устройства | Настроенные пины, значения и доступное управление выходами. |
| Сеть | Обнаруженные узлы. |
| Правила | Список, создание и удаление через поддерживаемые формы. |
| Консоль | Выполнение команд, доступных установленной прошивке. |

Набор и расположение элементов могут отличаться между выпусками. Для воспроизводимой настройки используйте [справочник консоли](06_CLI_Reference.md).

## Если страница не открывается

Проверьте подключение к нужной сети, фактический IP, запуск сервера и режим ожидания. На телефоне соединение с сетью без интернета иногда автоматически меняется; убедитесь, что телефон остаётся в сети ESP32.

Используйте панель в доверенной локальной сети. Публикация документации на GitHub не делает саму ESP32 доступной через интернет и не добавляет ей защищённый удалённый доступ.
